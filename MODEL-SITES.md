## Tips
- Download **GLB / glTF** when offered; the game uses three.js, which loads it directly.
- Put downloaded models in a `models/` folder next to `index.html`.
- Keep models low-poly (under ~20k triangles per fish) so the game runs smoothly on Quest 3.
